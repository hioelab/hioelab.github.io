This is the first post on our lab blog. Here we will share research notes, project updates, and announcements.

## How posts work

Each post is a single Markdown file in the `_posts` folder, named like `2026-06-03-title.md`. You can use **bold**, *italic*, lists, links, and images.

- Add a new file to `_posts`
- Fill in the title and date at the top
- Write your content below

That's it — the blog list updates automatically.

## 글이 동작하는 방식

각 글은 `_posts` 폴더 안의 마크다운 파일 하나이며, `2026-06-03-제목.md` 형식으로 이름을 짓습니다. **굵게**, *기울임*, 목록, 링크, 이미지를 사용할 수 있습니다.

- `_posts` 폴더에 새 파일 추가
- 맨 위에 제목과 날짜 입력
- 아래에 내용 작성

이게 전부입니다 — 블로그 목록은 자동으로 갱신됩니다.
